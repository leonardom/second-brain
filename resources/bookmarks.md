# Bookmarks — Curated Engineering Resources

> Tags: #dx #scalability #reliability #security

A curated list of high-quality engineering resources organized by topic.

## System Design & Architecture

- [Martin Fowler's Blog](https://martinfowler.com/) — Patterns, refactoring, microservices, DDD
- [High Scalability](http://highscalability.com/) — Real-world architecture case studies (Stack Overflow, Slack, etc.)
- [The System Design Primer (GitHub)](https://github.com/donnemartin/system-design-primer) — Comprehensive study guide
- [ByteByteGo Newsletter](https://blog.bytebytego.com/) — Visual system design explanations
- [AWS Architecture Blog](https://aws.amazon.com/blogs/architecture/) — AWS-specific patterns and case studies
- [Netflix Tech Blog](https://netflixtechblog.com/) — Distributed systems at scale
- [Uber Engineering Blog](https://www.uber.com/blog/engineering/) — Domain modeling, data platform, mobile

## Distributed Systems

- [Designing Data-Intensive Applications (excerpt)](https://dataintensive.net/) — Martin Kleppmann's website
- [The Log: What every software engineer should know](https://engineering.linkedin.com/distributed-systems/log-what-every-software-engineer-should-know-about-real-time-datas-unifying) — LinkedIn Engineering
- [Jepsen](https://jepsen.io/) — Distributed systems correctness testing and analyses
- [Papers We Love](https://paperswelove.org/) — Academic CS papers made accessible
- [FLP Impossibility explained](https://www.the-paper-trail.org/post/2008-08-13-a-brief-tour-of-flp-impossibility/) — Consensus fundamentals
